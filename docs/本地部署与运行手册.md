## 一、架构总览

单体应用，一个 `yudao-server` 聚合包承载全部 22 个业务模块：

```
yudao-server (Spring Boot 可执行 jar, 端口 48080, profile=local)
 ├─ yudao-module-system    系统底座（用户/角色/权限/字典/租户/通知）
 ├─ yudao-module-member    C 端会员（App 登录用户体系）
 ├─ yudao-module-inherit   非遗-传承人业务域（本项目二次开发核心）
 └─ ...其余业务模块（trade/pay/erp/crm/mes/iot/ai 等，默认未启用的可整体启动）
    前端: yudao-ui/yudao-ui-admin-vue3（当前为源码骨架，见 §六）
中间件: MySQL 8（业务库）+ Redis 5（缓存/分布式锁）
```

## 三、数据库初始化

1. 启动 MySQL，创建库（utf8mb4）：
```sql
CREATE DATABASE IF NOT EXISTS `ruoyi-vue-pro-jdk8` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

2. 按顺序导入 `sql/mysql/` 下 4 个 SQL：
```
sql/mysql/ruoyi-vue-pro.sql           # 系统底座：system/infra 全部表 + 菜单 + 字典 + 演示数据
sql/mysql/ruoyi-vue-pro-member.sql    # C 端会员表（App 登录用户体系）
sql/mysql/ruoyi-vue-pro-inherit.sql   # 非遗-传承人 5 张业务表 + 2 字典 + 菜单(7000-7034)
sql/mysql/quartz.sql                  # 定时任务 Quartz 表（local 用 jdbc JobStore）
```

> 数据源连接串（`application-local.yaml`）默认连 `jdbc:mysql://127.0.0.1:3306/ruoyi-vue-pro-jdk8`，账号 root/1234，与本机一致无需改配置。

## 四、Redis 启动

本机 Redis 非服务化，每次启动服务前先拉起（避免 Redisson 连接拒绝导致启动失败）：

```bash
cd .claude-build/redis
./redis-server.exe redis.windows.conf --port 6379 --save "" --appendonly no
```

> `--save "" --appendonly no` 关闭落盘，避免本机残留 rdb/aof 文件。

## 五、后端开发启动（不打包）

> 日常开发**不需要打包**，不需要 IDEA，VSCode / 任意终端都行。

### 1. 一键启动（MySQL + Redis + 后端）

**双击 `.claude-build/start-yudao.bat`**：确保 MySQL 服务 → 清理残留进程 → 弹 Redis 窗口 → 弹后端窗口（`mvn -pl yudao-server spring-boot:run`，约 13s 后后端窗口出现 `Started YudaoServerApplication` 即成功）。

> 后端窗口即可当普通终端用（Ctrl+C 停止）。如改过业务模块源码需先重装：
> `.claude-build/apache-maven-3.8.8/bin/mvn.cmd -pl yudao-module-inherit -am install -DskipTests -Dmaven.test.skip=true -Dspring-boot.repackage.skip=true`
> 注意：**必须用项目内这个 3.8.8 的 Maven**（`mvn.cmd` 在 PowerShell/cmd 里也能用），系统自带的 3.6.1 跑不了 flatten 插件。

### 2. 手动启动（备选，VSCode / 任意终端）

一次性准备（已在本机执行过）：把上游模块装进本地 Maven 仓库——
`.claude-build/apache-maven-3.8.8/bin/mvn -pl yudao-server -am install -DskipTests -Dmaven.test.skip=true -Dspring-boot.repackage.skip=true`

之后每次开发启动，在 VSCode 内置终端执行：
```
.claude-build/apache-maven-3.8.8/bin/mvn -pl yudao-server spring-boot:run
```

**备选：IDEA 的 Spring Boot 启动项：**

```
cn.iocoder.yudao.server.YudaoServerApplication
```

### 3. 通用说明

- 默认 `spring.profiles.active=local`（`application.yaml` 第 6 行），端口 48080。
- 本地已 `yudao.captcha.enable=false`、`yudao.security.mock-enable=true`，登录无需图形验证码。
- 就绪判定：控制台出现 `Started YudaoServerApplication`；或浏览器 `http://127.0.0.1:48080/doc.html` 返回 200。
- 若报 `Port 48080 already in use`：先关掉旧的 yudao-server 进程/窗口再启动。

## 七、前端现状与接入路径（已知缺口，非可运行状态）
  cd F:\01workspace\fyxcx\fyxcx0810\yudao-ui\yudao-ui-admin-vue3-full

> 本段描述的是**管理后台** `yudao-ui-admin-vue3`。App 端演示页（可运行）见 **§七·A**。

`yudao-ui/yudao-ui-admin-vue3` 当前是**纯源码骨架**：仅含 `src/` 下的 `api/inherit`、`api/mes`、`views/inherit`、`views/mes`（共 17 个 .vue/.ts 文件），**没有** `package.json`、`vite.config`、`main.ts`、`login` 页等构建与启动配置，因此**不可独立运行**。

> 该缺口是骨架未落地的历史遗留，按部署阶段约束（只修复阻塞本地运行的配置/环境问题、禁止新增业务功能、禁止为了部署方便改动业务代码），本次不补建前端脚手架。

后续接入路径（如需）：
1. 取官方 `yudao-ui-admin-vue3` 完整工程（含构建配置）；
2. 覆盖 `src/api/inherit/**`、`src/views/inherit/**` 到对应目录；
3. 在 `src/utils/dict` 或对应字典常量处注册 `inherit_` 两个字典（传承人级别/资质类型）；
4. 在路由/菜单里注册 4 个 inherit 页面路由（菜单已在数据库 SQL 中配好 id 7000-7034）；
5. `npm i && npm run dev`（默认代理 /admin-api /app-api 到 48080）。

`yudao-ui/inherit-app-uniapp/` 是一个**已可运行**的 uniapp(vue3) 演示工程，用来验证传承人模块的 App 公开接口（列表/详情/作品/资质/关联项目/关注）：

| 项 | 值 |

| 依赖后端 | 需先按 §四 启动 Redis + yudao-server，并已用 §五 脚本造好演示数据（或至少 3 条已审核+展示+启用的传承人） |

4. 后端地址改在 `src/utils/request.js` 顶部的 `BASE_URL`。

## 八、避坑要点（本机实测）

| 坑 | 现象 | 规避 |
| --- | --- | --- |
| Maven 版本 | flatten-maven-plugin 1.7.2 报错 | 用项目内 `.claude-build/apache-maven-3.8.8`，构建带 `-Dflatten.skip=true -Dflatten.updatePomFile=false` |
| Redis 非常驻 | Redisson 连接拒绝，启动失败 | 先起 §四 的 redis-server.exe |
| 租户头缺失 | 登录接口报「租户标识未传递」 | admin-api 请求一律带 `tenant-id: 1` |
| git-bash curl 中文 | Jackson `Invalid UTF-8` | 中文入参写进 UTF-8 文件，`curl --data-binary @file` 发送 |
| 单元测试 | H2 2.x `year` 保留字 / tinyint 越界 | 测试 H2 URL `NON_KEYWORDS=value,YEAR`；测试 DDL 将 gender/is_recommend 放宽为 int；跑单测必须 `-pl yudao-module-inherit -am test` 且联网（surefire provider 需下载） |
| 端口占用 | 48080/6379 被占 | 结束旧 `yudao-server.jar` / `redis-server.exe` 进程后再启动 |

## 九、附：一次完整启动的耗时参考与健康检查

- 冷启动（先 Maven 打包再 java -jar）：打包数分钟，jar 启动约 30s。
- 就绪判定：`curl http://127.0.0.1:48080/doc.html` 返回 200；或 POST `/admin-api/system/auth/login`（带 `tenant-id: 1`）返回 `code=0`。
- 停止：Ctrl+C 结束 java；Redis 用 `redis-cli.exe shutdown nosave` 或结束进程。
