# IM 模块测试用例清单（inherit-app-uniapp）

> 测试对象：小程序 IM 功能（后台账号桥接 + 核心聊天）
> 对应页面：`pages/im/{index,chat,friendAdd,friendRequests,groupCreate,groupInfo}.vue`
> 后端：yudao-server（48080，profile=local），IM 模块已启用，16 张 IM 表已建
> 执行日期：2026-08-16
> 执行方式：API 级功能测试（curl），结果填入「结果」列；WebSocket/UI 类标注「需人工验证」

## 测试环境与前置条件

- 后端接口统一前缀 `/admin-api`，请求头必须带 `tenant-id: 1`
- 登录：`POST /admin-api/system/auth/login`，演示账号 admin/admin123
- WebSocket：`ws://127.0.0.1:48080/infra/ws?token={refreshToken}`
- **需要 2 个以上后台账号**：admin（user id=1）+ 临时账号 B（imtestb/id=226）与 C（imtestc/id=227），已按 checklist 指引创建、分配「普通角色」(roleId=2)，测试后已删除
- 每个用例的结果列：PASS / FAIL / 需人工验证 / N/A
